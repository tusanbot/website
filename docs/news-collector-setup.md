# راه‌اندازی جمع‌آوری روزانه اخبار توسن

## پیش‌نیازها
1. ابتدا فایل `supabase/migrations/20261010_news_announcements.sql` را روی پروژه Supabase اجرا کنید.
2. در محیط اجرای Next.js این متغیرها را تنظیم کنید:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY` (فقط سمت سرور؛ هرگز با پیشوند NEXT_PUBLIC تعریف نشود)
   - `NEWS_CRON_SECRET` (یک مقدار تصادفی و محرمانه)
3. پس از استقرار، در `/admin/news` با حساب مدیر وارد شوید و نشانی RSS/Atom منابع معتبر را اضافه کنید.

## زمان‌بندی در cPanel
یک Cron Job روزانه (مثلاً ساعت 06:15) بسازید و این فرمان را اجرا کنید؛ دامنه و مقدار محرمانه را با مقادیر واقعی جایگزین کنید:

```bash
curl -fsS -H "Authorization: Bearer YOUR_NEWS_CRON_SECRET" "https://www.tusancn.ir/api/cron/news-collect" >/dev/null 2>&1
```

از قرار دادن مقدار واقعی محرمانه در مخزن GitHub خودداری کنید. بهتر است دستور Cron از فایل تنظیمات با دسترسی محدود بخواند.

## رفتار ایمن
- مسیر جمع‌آوری فقط با توکن محرمانه قابل فراخوانی است.
- فقط فیدهای RSS/Atom بررسی می‌شوند؛ صفحه‌های معمولی HTML در این نسخه خودکار استخراج نمی‌شوند.
- هر مورد جدید با وضعیت `review` ذخیره می‌شود و به صورت عمومی نمایش داده نمی‌شود تا مدیر آن را منتشر کند.
- تکرار بر اساس نشانی منبع و شناسه فید حذف می‌شود.
- این نسخه متن فید را پاک‌سازی و خلاصه کوتاه می‌کند؛ تولید خلاصه هوش مصنوعی و بررسی دقیق شرایط/تاریخ‌ها مرحله بعدی است.
