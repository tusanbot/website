# Tosan CafeNet Bookmarks Extension

Source package for the downloads at `/tools/extension`.

- Chrome and Edge: ZIP downloads can be extracted and loaded from the browser's extensions page with Developer mode enabled.
- Firefox: package adds a Gecko extension ID, but a public AMO-signed XPI still requires submission and signing through Firefox Add-ons.
- The download endpoint generates browser-specific ZIPs from these files.
- Site URLs are seeded from the current website tool catalog where possible. External government portals may change; validate them before store submission.
- No extension store has been published yet. Store listing links should be updated after IDs/URLs are assigned.
